# 配当・利回りの用語対応表

画面に出る配当・利回りの名前と、意味・税区分・算出条件の対応表。
以後の追加もこの表に従い、同じ値に別名を付けない。
文言の実体は `frontend/src/ui/labels.rs` に置き、画面側に同じ意味の文言を直書きしない。

## 年間配当・予想

| 画面に出る名前 | 意味 | 税区分 | 算出条件 |
| --- | --- | --- | --- |
| 年間予想配当(税引前) | ホーム集計帯・資産管理の帯・列・詳細・銘柄検索の保有情報の年間予想配当 | 税引前 | 1株配当(会社予想)×保有数 |
| 年間予想配当(税引後) | ホーム配当カードの予想。集計帯の税引前とは別物 | 税引後 | 年間予想配当(税引前)×(1−実効税率)。実効税率は配当実績の加重平均、実績なしは法定税率 |
| 進捗率 | 配当金が年間予想配当(税引後)にどこまで届いたかの率 | 税引後 | 配当金÷年間予想配当(税引後)。100% を超えたらバーは満タンで止め「予想を上回りました」と出す |

資産管理のPC表の列見出しだけは幅の都合で「年間予想配当」と短くし、見出しの説明(title・注記)に「(税引前)」を出す。列の値・集計帯・詳細・銘柄検索は「年間予想配当(税引前)」のままにする。

## 利回り

| 画面に出る名前 | 意味 | 税区分 | 算出条件 |
| --- | --- | --- | --- |
| 取得額利回り | 資産管理・銘柄検索の利回り(旧名「取得額基準利回り」も同じ値) | 税引前 | 予想年間配当÷取得額 |

旧名「年間配当参考額」「取得額基準利回り」は使わない。
`labels.rs` の単体テストが `frontend/src` に現れないことを確かめる。

## 受取額・残り

| 画面に出る名前 | 意味 | 税区分 | 算出条件 |
| --- | --- | --- | --- |
| 今年の配当金(税引後) | ホーム配当カードの見出し | 税引後 | - |
| 配当金(税引後) | 取引明細の帯の主役(配当金タブ)。税区分は帯にだけ書く | 税引後 | - |
| 配当金 | 取引明細の月見出し・カードの見出し(配当金タブ)。税区分は付けない | 税引後 | 帯の税引後と同じ合計 |
| 実現損益(税引後) | 取引明細の帯の主役(国内株式・投資信託タブ)。税区分は帯にだけ書く | 税引後 | - |
| 実現損益 | 取引明細の月見出し・カードの見出し(国内株式・投資信託タブ)。税区分は付けない | 税引後 | 帯の税引後と同じ合計 |
| 税引後 | 取引明細の行・ダイアログの配当金額(行だけでは分からないため行にも付ける) | 税引後 | - |
| 配当金(税引前) | 取引明細の帯・ダイアログの税引前の内訳 | 税引前 | - |
| 実現損益(税引前) | 取引明細の帯の税引前の内訳(国内株式・投資信託タブ) | 税引前 | - |
| 残り | 予想から配当金を引いた残額 | 税引後 | 年間予想配当(税引後)−配当金 |
| 予想を N 上回り | 残りが負のときの書き分け | 税引後 | 配当金−年間予想配当(税引後) |
| 予想を上回りました | 進捗率が 100% を超えたときの状態 | 税引後 | 配当金÷年間予想配当(税引後) > 100% |

## 禁止語

画面の見出し・ラベルでは「受取」「損益」を単独で使わない。
受け取った配当の呼び名は「配当金」に統一し、月の見出し・カード・件数の行に税区分を繰り返さない
(件数行の「金額は税引後」は付けない。税区分は帯の「配当金(税引後)」「実現損益(税引後)」にだけ書く)。
「受取型」(分配金コース)「評価損益」「実現損益」の複合語は使える。
旧名「年間配当(予想)」「年間予想(税引後)」「価格基準日」は使わない。
株価の日付は全画面「株価 YYYY/MM/DD 時点」と書く(銘柄検索の保有情報・資産管理の詳細を含む)。
`labels.rs` の `FORBIDDEN_TERMS` の単体テストが `frontend/src` への直書きを止める。
