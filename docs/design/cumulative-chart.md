# 配当累計グラフの作法

- 累計の方向と規模が読めるよう、0 を含む等間隔の目盛りと薄い補助線を置く。数値軸は上限を明示し、比較線と単位を取り違えない。
- 凡例は線の見本と名前を対応させる。線の右端に直接ラベルを置く場合は、凡例と重複させず、狭い幅でも値が切れない位置に置く。
- 線は細く保ち、塗りは主系列の下だけを低い不透明度で示す。入金のない月は累計が横ばいであることを線形状で伝え、予測値は実績と異なる破線にする。
- 色は既存の chart / surface / text トークンを使う。系列の識別は色だけに任せず、線種・ラベル・吹き出し・読み上げ用データ表を残す。ライト・ダークと小画面で確認する。
- 吹き出しには月の受取額と累計額を示す。外側操作で閉じられ、キーボードでも操作できること。

## 参考にした実在アプリ

- Apple Stocks は期間選択とチャートの長押しによる時点の値確認を案内している。値の推移を見て、必要な時点を詳しく確認する流れの参考にした。
  - https://support.apple.com/en-mz/guide/iphone/iph1ac0b1bc/ios
- Robinhood は基本チャートで期間別のポートフォリオ推移を示し、チャート設定で表示を調整できる。期間と線の読み取りを中心にする参考にした。
  - https://robinhood.com/us/en/support/articles/using-the-charts/
- マネーフォワード ME は資産推移を時系列で把握する利用例として参照した。記事掲載の画面では期間単位の推移を確認できる。
  - https://media.moneyforward.com/articles/7338?af=authors_list
