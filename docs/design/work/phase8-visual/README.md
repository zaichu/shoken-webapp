# Phase 8 ホーム見た目(visual)

Phase 5 の見本に対し「全体の雰囲気・見た目が悪い」との判断を受け、Phase 3 の骨格(集計帯→資産の構成→月別配当→保有一覧)は保ったまま、見た目だけを作り直したホームの方向案。数値はすべて `../phase5-codex/data/fixtures.json` の架空データを直書き(評価額 ¥28,593,148 = 国内株式 ¥9,149,807 + 投資信託 ¥19,443,341、前日比 +¥154,488、年間配当 税引前 ¥3,969,907 / 税引後 ¥3,163,438、保有3件、最近の配当 2026/12/24 ¥10,957・2026/12/10 ¥23,905)。

## 現行の画面から変わった点(案4)

現行(`before/current-home-*.png`)との比べどころ:

1. 紺の3分割集計帯・予想vs実績グラフ・口座別バーをなくし、縦1列(最大720px)で上から下に読む形にした
2. 明細をすべて「左=名前(長いものは…で省略)・右=金額」の同じ行に統一し、金額の右端をページ全体で一本線にそろえた
3. 色を黒・灰+利益緑・損失赤・グラフ1色(緑の濃淡)だけにし、見出しや帯の色をやめた

## 守る規則と守った場所(案4 `idea4-simple.html`)

1. 縦1列で読む: `.wrap{max-width:720px}` で中央1列。左右併記は `.row` の「名前と金額」の中だけ
2. 同じ型のセクション: `section` = `h2`(見出し)→`.sum`(1行の要約)→`.rows`(明細)。カード・枠・影なし、区切りは `section{border-top}` の細線1本+余白
3. 同じ「行」の型: `.row` = 左 `.name`(1行・`ellipsis`)+`.sub`(2段目・補足)、右 `.amt`。構成・月別(12か月)・保有の全明細で同じ型
4. 数字: `.amt` と `.total` は `tabular-nums`・右そろえ・書式 `¥1,234,567`。大きさ3段(hero 52px / `.sum` 22px / `.row` 15px)で同段は同サイズ・同太字
5. 色: 文字は `--ink` と `--muted`(灰)の2つだけ。色は `.up`(緑)/`.down`(赤)とグラフの `--g-deep`/`--g-pale`(同色相の濃淡)だけ。見出し・帯に色なし
6. グラフ: 構成は `.bar100`(68.0%/32.0%の1本) 、月別は `.bars`(数字ラベル+下に「月」1回、値ラベルは6月の356.5万だけ)
7. 書体: Noto Sans JP の1種類、太さは `400` と `700` のみ(Google Fonts 指定もその2つ)
8. スマホ390px: 金額・見出しは `nowrap`/`ellipsis`+`clamp` で改行なし。`shots/idea4-simple-mobile-{light,dark}.png` で全金額1行を目視済み(機械検査でも折返し0・はみ出し0)
9. 数字: fixtures.json の値(合計・月別税引前/税引後・保有3行・前日比)を直書き

共通: Noto Sans JP(Google Fonts、落ちたらシステムフォント)、数字は tabular-nums。紫〜青グラデ・クリーム+セリフ・全面角丸+影・絵文字見出しは使わない。各 html は1ファイルで PC/スマホ両対応、`?theme=light|dark` と `prefers-color-scheme` でライト/ダーク切替。撮影は `tools/shoot.py`(Playwright、PC 1440px・スマホ 390px × ライト・ダークの full-page)。

現行のホーム(`before/current-home-*.png` = phase1-opencode の現行アプリ撮影。紺の3分割集計帯、予想vs実績・達成率つき配当グラフ、口座別バー)との比べどころは各案の節に3点ずつ書いた。

## スマホ集計帯の改行対応

390px で金額が見出し途中や金額途中で折れないよう、各案とも集計帯の金額は `white-space:nowrap` + 段階フォント(`clamp`)で1行に収めた。収まらない表(案2の保有一覧7列)はモバイルで縦積み(項目名: 値の行並び)に組み替えた。`shots/` のモバイル6枚で全金額の1行収まりを目視済み。

## 案1 ミニマル(`idea1-minimal.html`)

白地に広い余白。64px の評価額だけを主役にし、区切りは 1px の線だけ(枠・影なし)。構成は線の横棒、月別は細い棒、保有一覧は罫線だけの表。読む順番が上から下に一直線。
現行からの変更: (1)紺の3分割集計帯をやめ白地に評価額1点だけを大きく置いた (2)配当グラフを「予想vs実績・達成率」から「12か月の実績のみ」の細棒に変えた (3)口座別バーと銘柄リストをなくし一直線に並べた。
色: 白 #FFFFFF / 文字 #1A1A1A / 補助 #6F7377 / 線 #E4E4E4、上昇だけ深緑 #0B6B3A(ダークでは #5FCE8F)。書体: Noto Sans JP 400/500/700。

## 案2 金融系(`idea2-finance.html`)

深い紺の見出し帯に集計を集約し、以下は罫線の表で詰めた高密度レイアウト。金額はすべて右そろえ、内訳列で検算できる(取得総額の内訳、月別の税引後、国内株式の内訳 27.8%/4.2%など)。構成の横棒は紺と金で分類だけ色分け。
現行からの変更: (1)紺の帯は残し金額を右そろえの表にして内訳列で検算できる形にした (2)配当は12か月バー+主要月だけの表に集約し予想・達成率をなくした (3)保有一覧に合計行を付け口座別バーは削った。
色: 帯 #1C2F47 / 地 #F4F5F6 / 紙 #FFFFFF / 金 #8A6D2B、上昇 #0D6B38・下落 #B3261E。書体: Noto Sans JP 400/500/700。

## 案3 カード型(`idea3-cards.html`)

淡い緑がかった地(#E9EFE9)の上に白カードを置き、ドーナツと月別棒を大きく見せる。見出しは小さな四角マーカー+文字だけ。数字はカード内で大きく、保有一覧は銘柄ごとに行を分けた読みやすい形。親しみは丸みと緑で出し、影はほぼ使わない(1px 罫+角丸14px)。
現行からの変更: (1)紺の帯をやめ淡い緑地+白カードにし評価額・損益・配当を分けて置いた (2)ドーナツと月別棒を大きくし予想・達成率や口座別バーをなくした (3)保有一覧を銘柄ごとの行にし評価額を右に大きく出した。
色: 地 #E9EFE9 / カード #FFFFFF / 文字 #22301F / 主緑 #1F6B44 / 淡緑 #E0ECDF、月別ピークのみ濃緑。書体: Noto Sans JP 400/500/700。

## 案4 シンプル(`idea4-simple.html`)

3案への指摘(すらすら読めない・数字と色がガタガタ)を受け、1案に絞った作り直し。上記8規則のとおり: 縦1列・全セクション同型・全明細同行型・金額右端一本線・黒灰+緑赤+緑濃淡のみ・Noto Sans JP 400/700。
