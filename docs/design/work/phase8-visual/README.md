# Phase 8 ホーム新案(スマホ・PC)

`home-mobile.html`(390px)と `home-pc.html`(1280/1440px)の2ファイル。数値はすべて `../phase5-codex/data/fixtures.json` の架空データを直書き(評価額 ¥28,593,148 = 国内株式 ¥9,149,807 + 投資信託 ¥19,443,341、評価損益 +¥1,552,488 +5.74%、年間予想配当(税引後) ¥3,163,438、受取(税引後) ¥3,163,438、最近の配当入金3件、評価損益の大きい銘柄3件)。受取と予想はどちらも税引後にそろえている(並べる2つの数字は同じ基準にする)。年間予想(税引後)は fixtures の `annualForecast.afterTax`(税引前 ¥3,969,907 − 税額 ¥806,469 = ¥3,163,438)に足し、`node data/build.mjs` の検査(382 asserts)を通過。fixture上は通年の配当実績が予想と一致するため、予想と受取は同額になる。現行のホームに載っている内容だけを載せ、保有一覧の全件・前日比は足していない。`?theme=light|dark` と `prefers-color-scheme` でライト/ダーク切替。撮影は `tools/shoot.py`(Playwright)。

## 現行から変えた点

スマホ3点:

1. 一番上を3要素だけにした(ラベル「評価額」→評価額 30px左寄せ→評価損益 1行→価格基準日)。年間予想配当は一番上から外し、配当のセクションに入れた。
2. 配当カードの「1611%」と細い進捗バーをやめ、要約は「受取 ¥3,163,438 / 予想 ¥3,163,438」の1行にした(どちらも税引後、fixtures annualForecast.afterTax)。棒グラフは170px・税引後の単棒・月ラベルは1・4・7・10月だけ・6月に税引後 ¥2,840,712 の値ラベルにした。前年は税引後の月別がないため載せない。
3. 円グラフと口座別の色札をやめ、資産の内訳は1本の横棒(8px・2色)+同じ行の型に統一した。CSVの取り込みは見出し帯から外し、ページ最下部の文字リンク1行にした。

PC3点:

1. 紺の帯をやめ、3つの数字(評価額 32px・評価損益 24px・年間予想配当(税引後) 24px、ラベル 13px灰)を地の上に横並び・縦の細い線区切りにした。価格基準日・取り込み日は右端に 13px灰で置いた。hero の予想は fixtures annualForecast.afterTax と明示し、本番の年間予想配当(税引前)とは基準を分けている。
2. 下を2列(左2:右1、間24px)にし、左に今年の配当金(棒グラフ高さ240px、税引後の単棒、月ラベル12か月、6月に税引後 ¥2,840,712 の値ラベル)+最近の配当入金、右に資産の内訳+評価損益の大きい銘柄を置いた。
3. ドーナツと口座別の色札をやめ、横棒+行の型に統一した。最大幅 1200px・中央にした。
