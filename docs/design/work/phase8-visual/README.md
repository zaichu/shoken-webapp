# Phase 8 ホーム見た目(visual)

Phase 5 の見本に対し「全体の雰囲気・見た目が悪い」との判断を受け、Phase 3 の骨格(集計帯→資産の構成→月別配当→保有一覧)は保ったまま、見た目だけを作り直したホームの方向案。数値はすべて `../phase5-codex/data/fixtures.json` の架空データを直書き(評価額 ¥28,593,148 = 国内株式 ¥9,149,807 + 投資信託 ¥19,443,341、前日比 +¥154,488、年間配当 税引前 ¥3,969,907 / 税引後 ¥3,163,438、保有3件、最近の配当 2026/12/24 ¥10,957・2026/12/10 ¥23,905)。不採用案(案1〜4)は削除済み。現行案は `idea5-current-color.html` の1案のみ。

共通: Noto Sans JP(Google Fonts、落ちたらシステムフォント)、数字は tabular-nums。紫〜青グラデ・クリーム+セリフ・全面角丸+影・絵文字見出しは使わない。html は1ファイルで PC/スマホ両対応、`?theme=light|dark` と `prefers-color-scheme` でライト/ダーク切替。撮影は `tools/shoot.py`(Playwright、PC 1440px・スマホ 390px × ライト・ダークの full-page)。

現行のホーム(`before/current-home-*.png` = phase1-opencode の現行アプリ撮影)との比べどころは下の表と html 冒頭のコメントに書いた。

## 案5 現行色(`idea5-current-color.html`)

縦1列(最大720px)・同型セクション(見出し→要約→明細)・同行型明細(左=名前・右=金額、補足は2段目)・金額の右端一本線・3段文字・改行なし。色は `frontend/style/input.css` の現行トークンのみ(紺 `#0f2a4a`は見出し・主役数字の文字色、青アクセント `#1d4ed8`/ダーク `#8fb3f7`はリンク・入口、利益緑/損失、金は現行どおり)。面の塗りは棒グラフと割合の横棒だけ。新色なし。
- 月別配当: 現行と同じ内容(受取額・前年比較・今年/前年の2本並び棒)。明細は直近の入金2行だけ。前年値(2025年・税引前、合計 ¥3,339,000)は `../phase5-codex/data/fixtures.json` に `previousYearDividends` として追加し、`node data/build.mjs` の検査(379 asserts)を通過・生成物に差分なしを確認
- 操作: 上ナビ4項目・アカウント・下ナビ4項目を残置(下ナビはスマホのみ表示、撮影写り込み回避のためフロー配置)。CSV取り込みは保有一覧末尾の1行に一本化
- 現行からの変更: (1)紺帯をやめ地の上に評価額・損益の大きな数字を置き金額の右端を一本線に (2)12か月表をやめ受取額+前年比較+直近2行に (3)口座別バーをやめ構成は青/紺の1本棒に。各 html 冒頭のコメントにも同じ3点を記載

- `idea5-current-color.html` — 現行案(PC/スマホ両対応1ファイル)
- `shots/`: 案5の4枚(PC/モバイル × ライト/ダーク)。全枚、文字の切れ・重なり・はみ出しなしを目視済み(モバイルは全金額1行を1枚ずつ確認)
- `before/`: 現行ホームの撮影4枚(phase1-opencode の現行アプリ撮影を複写。比較用、編集なし)
- `tools/shoot.py`: 撮影スクリプト
