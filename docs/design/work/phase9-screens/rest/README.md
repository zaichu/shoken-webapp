# Phase 9 rest担当分の新案(スマホ・PC)

対象: 銘柄検索(`/search`、結果・保有情報・外部リンク11件)、設定(`/settings`、7セクション)、
ログイン(`/login`)、未ログイン時のホーム(`LoginPrompt`)、404(`/404`)、
ログイン一覧(管理者、`/admin/logins`)、ダイアログ・パネル類(9種+通知リンクの確認)。
`*-mobile.html`(390px)と `*-pc.html`(1280px)の14ファイル。数値はすべて `../phase5-codex/data/fixtures.json` の
架空データを直書き(評価額 ¥28,593,148 は検索・ホームと無関係のため使わず、9901 架空青空電機の
評価額 ¥1,200,000・損益 +¥200,000 +20.00%、9902 架空食品ホールディングスの評価額 ¥7,949,807・
損益 +¥1,352,488 +20.50%、配当 11/08 ¥31,874(税引前¥40,000・税額¥8,126)・11/10 ¥44,823(税引前¥56,250・税額¥11,427))。
並べる数字は同じ基準にそろえた(損益は金額+%・税引後相当の表示は税引後の行だけに置く、基準日 2026/11/13 を明記)。
`?theme=light|dark` と `prefers-color-scheme` でライト/ダーク切替。撮影は `tools/shoot.py`(Playwright)。
生成は `tools/gen.py`(phase9-screens/opencode の共通CSSと同一。gen→shoot の順で回す)。
先行5画面(opencode/)・ホーム(phase8-visual)の型・数字にそろえた。本番コードは変えていない(このフォルダ配下のみ)。

表示例の注記: 保有情報の口座別(特定50株+NISA成長50株・取得単価に小数 ¥10,123.46/¥9,876.54)は
複数口座の型を示す表示例。合計100株・評価額の合計は fixtures と一致させている。

## 現行から変えた点

銘柄検索3点:

1. 検索欄をカード化し、実行ボタンを「銘柄を検索」1つにした(スマホ・PC共通の部品)。結果は保有情報→銘柄詳細→外部リンクの順に積んだ。「資産管理に戻る」の戻りは主画面の見本からは外し、現行どおり保有ありで資産管理の行から来たときだけ出す。
2. 保有タイルの羅列をやめ、左=項目名(灰)・右=値(太字)の定義行カードにした。口座別はホームと同じ行の型にした。
3. 外部リンク11件(現行の11件をすべて残す)を同じボタンの見た目にし、スマホ2列・PC4列にした。

設定3点:

1. 7セクションをホームと同じ白カードにし、スマホは行の型の目次+縦積み、PCは左目次+2列にした。目次は色札(チップ)をやめ青文字のリンクの並びにした。赤枠・赤背景は使わず、危険操作の「削除…」だけ赤文字にした。
2. テーマ・自動ログアウトは塗りの切り替えをやめ、他の行と同じ定義行(左=項目名・右=値)にした。面を紺で塗るのは主ボタンだけにした。
3. 端末・履歴は行の型(左=名前+補足、右=操作)にし、結果の札はやめて2段目の文字にした(失敗だけ赤文字)。

ログイン・未ログイン時のホーム・404(3点):

1. いずれも中央のカード1枚+状態の例だけにした。下部ナビ・帯は置かない(現行の Login/NotFound は下部ナビなし)。
2. 未ログイン時のホームは「評価額 —」の1行+「ログインしてください」カード+公開の銘柄検索入口だけにした(ホームの集計は載せない)。
3. 404は「404 - ページが見つかりません」+「ホームに戻る」+関連3リンクを残し、認証・権限の振り分け(未ログイン→ログインへ、管理者以外→404)を同じ行の型で添えた。

ログイン一覧(管理者)3点:

1. 紺の帯をやめ、見出しの下に検索欄+「並べ替え」ボタン(スマホ)/列名クリック(PC)の全画面共通部品にした。
2. 条件(メール・場所・期間・並べ替え)をチップ+「この条件で絞る」ボタンにし、解除の操作を1か所にした。
3. 行はホームと同じ型(左=メール+日時・場所、右=結果バッジ)にし、PCは表(日時・メール・結果・場所の列名クリック)・スマホは行にした。

ダイアログ・パネル類3点:

1. 9種+通知リンクの確認をすべて同じカード型(見出し+右に「閉じる/クリア」→定義行・行・ボタン)にした。期間の種類は塗りの切り替えをやめ下線のタブにした。スマホ=下部シート・PC=中央・ポップオーバー・右パネルの出し分けは注記にした。
2. 削除確認は対象・件数・「この操作は取り消せません」を明示し、実行ボタンに件数(18件を削除する)を載せた。
3. アカウントメニューは現行の6項目(設定・データをエクスポート・ログイン履歴・管理者・ログアウト・アカウントを削除)をすべて残し、行の型にした。アカウント削除の確認は現行の `AccountDeleteDialog`(パスワード入力なし: 見出し+説明+取消不能の注意+キャンセル/削除する)に合わせた。
