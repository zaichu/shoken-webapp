# Phase 9 opencode担当分の新案(スマホ・PC)

対象: 資産管理(`/assetbalance`、タブ すべて/国内株式/投資信託)、構成比(`/assetbalance/composition`)、
保有ファンド詳細(`/assetbalance/funds/:id`)、取引明細(`/receipts`、タブ 配当金/国内株式/投資信託)、CSV管理(`/csv`)。
`*-mobile.html`(390px)と `*-pc.html`(1280px)の10ファイル。数値はすべて `../phase5-codex/data/fixtures.json` の
架空データを直書き(評価額 ¥28,593,148、評価損益 +¥1,552,488 +5.74%、受取(税引後・基準日2026/11/13まで) ¥3,128,576(16件、12月は基準日以降のため除く)、
国内株式の実現損益(税引後) +¥99,017、投資信託の実現損益(税引後) +¥147,282、年間配当(税引前)合計 ¥3,969,907)。
並べる数字は同じ基準にそろえた(受取と予想は税引後、帯の損益は税引後、構成比は基準を明記)。
`?theme=light|dark` と `prefers-color-scheme` でライト/ダーク切替。撮影は `tools/shoot.py`(Playwright)。
構成比の銘柄別内訳は `../phase5-codex/data/build.mjs` の検査(407 asserts)で検算済み(9902 ¥3,933,907 99.1%、9901 ¥36,000 0.9%、投信は算出不可)。
生成は `tools/gen.py`(共通CSSから10ファイルを生成する。再撮影時は gen→shoot の順で回す)。
本番コードは変えていない(このフォルダ配下のみ)。

## 現行から変えた点

資産管理3点:

1. 紺の帯をやめ、一番上はホームと同じ3要素(評価額30px→評価損益→価格基準日)だけにした。年間予想は出さない。
2. 円グラフ相当と口座別の色札をやめ、明細はホームと同じ行の型(左=名前+補足、右=金額+損益)に統一した。
3. 検索と並べ替えを全画面共通の部品にした(スマホは「並べ替え」ボタン1つ、PCは列名クリック)。タブ・「構成比を見る ›」は残した。

構成比3点:

1. ドーナツと凡例をやめ、ホームと同じ1本の横棒(高さ8px)+行の型に統一した。3区分目は灰で足し、新色なし。
2. 基準切替(評価額/年間配当(税引前))と区分タブ(銘柄別/商品別/口座別)を同じ部品の見た目にし、基準の注記(合計・保有全体)を添えた。
3. 投信の年間配当は算出不可のため「—」で出し、欠測の扱いを現行どおりにした。

保有ファンド詳細3点:

1. タイルの羅列をやめ、左=項目名(灰)・右=値(太字)の定義行カードにした(値はすべて右そろえ・改行なし)。
2. 損益・前日比は±符号+金額+%と色、0と「—」は符号も色も付けない。更新待ちの行は理由を添えた。
3. PCは2列(明細+状態の例)にし、スマホは1列で上から読む形にした。

取引明細3点:

1. 紺の帯をやめ、一番上は「受け取った配当金(税引後)」の1数字+期間だけにした。株・投信タブの帯(実現損益(税引後))は同じ型のカードで併記した。
2. 行詳細(税引前・税額・税引後の内訳)を1行分だけ開いた例で示し、行の型は閉じた行と同じにした。
3. 検索と並べ替えを全画面共通の部品にした(スマホは「並べ替え: 入金日の新しい順」ボタン、PCは列名クリック)。月見出しの右に受取/損益の小計を残した。

CSV管理3点:

1. 見出し帯をやめ、取得カード(「楽天証券から最新のデータを取得」+「すべて取得」ボタン)をカード化した。
2. 5行の表は行の型に統一(左=種類+状態、右=保存済み件数)。PCは表(状態列つき)、スマホは行の型にした。状態色は緑=今日更新・赤=取得失敗・灰=それ以外だけ。
3. 行メニュー(再取得/ファイルから取り込み/削除)と削除確認(件数+取消不能の明示)を同じ型のカードで例示した。
