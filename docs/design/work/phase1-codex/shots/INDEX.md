# 撮影一覧

全画像は Playwright と `frontend/scripts/ui-shots/` の架空データで撮影した。管理者画面は `admin-logins` モック、ログイン画面は 401 モックを使用。API 通信は同スクリプトで差し替え、localhost 以外とモック外 API は遮断した。画像はすべて 300KB 以下。

撮影は 15 系列 × 5 viewport × 2 テーマ = 150 ケース。表・一覧のスクロール後を含めて 260 枚を生成し、追加で管理者画面の18枚を撮影した。管理者の通常一覧ケースのモバイル用重複12枚を除き、最終成果物は266枚。PC 基準は 1280×800、スマホ基準は 390×844。既存撮影スクリプトの追加 viewport (1024×768、1440×900、1920×1080) とスクロール後画像も保持した。

## ファイル名

`<系列>-<状態>-pc|mobile-light|dark.png`。基準幅は `home-pc-light.png`、`home-mobile-dark.png` のように記録する。追加幅は `home-1024x768-pc-light.png`、スクロール後は `home-scrolled-pc-light.png`。生成画像を整理しているため、縮小した高解像度画像は実ピクセル寸法が元と異なる場合がある。
