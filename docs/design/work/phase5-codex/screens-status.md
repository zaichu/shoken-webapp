## 数値・制作上の根拠と制限

- 採用方針は [Phase 3決定](../phase3-decision.md) の「Cを骨格、Bのスマホ、AのPC詳細パネル」。色・部品は [Phase 4 tokens.css](../phase4-codex/tokens.css) と [部品見本](../phase4-codex/html/components.html) を参照。
- Phase 2 の根拠は [Codex UX監査](../phase2-codex/ux-audit-codex.md) の「ホームのモバイル上部」「長い銘柄名」「構成比チャート」「空・エラー表示」と、[OpenCode UX監査](../phase2-opencode/ux-audit-opencode.md) の AS-1、SE-2、CO-1。課題はデザイン案上で反映し、実装後の解決を意味しない。
- 金額は依頼に記載された評価額 ¥28,593,148、取得総額 ¥27,040,660、評価損益 +¥1,552,488、年配当(税引後) ¥3,163,438 を使用。資産内訳は国内株式 ¥20,000,000 + 投資信託 ¥8,593,148 = ¥28,593,148。銘柄別取得額は ¥10,800,000 + ¥7,647,512 + ¥8,593,148 = ¥27,040,660。損益は +¥1,200,000 + ¥352,488 + ¥0 = +¥1,552,488。
- 月別配当は 1月 ¥180,000、2月 ¥0、3月 ¥210,000、4月 ¥190,000、5月 ¥220,000、6月 ¥260,000、7月 ¥280,000、8月 ¥210,000、9月 ¥330,000、10月 ¥250,000、11月 ¥450,000、12月 ¥583,438。合計 ¥3,163,438。
