# コンセプト C：情報密度と視認性を両立する UI

## 骨格

既存の上ナビと集計帯の流れを維持し、ページを「要点 → 詳細」の2段に整理する。上段は評価額・損益・配当見通しなどの大きな数字をカードで提示し、関連する配当推移・資産配分の図を同じ文脈に置く。下段は必要な情報だけを先に示す一覧で、行を開くと取得額・基準価額・配当、または税引前配当・税額を確認できる。

資産一覧は行高44pxを基本とし、列数を整理して銘柄名、種別・口座、数量、評価額、損益を示す。展開領域には補足項目をまとめる。取引明細は日付と銘柄、口座、数量、税引後額を一覧にし、展開すると税引前・税額・税引後の内訳を示す。余白と行間を広げて視線の移動を抑え、固定テーブルの横幅に依存しない。

スマホは要点カードを縦に並べ、資産と取引明細をアコーディオン形式にする。要約から必要な行だけ開け、画面幅に応じて詳細も縦並びになる。ホームでは配当チャート、内訳の円グラフと口座別金額、評価損益上位、最近の入金を要点と関連づけて並べる。

## 視覚と言葉

既存上部ナビの濃紺を継承し、カードの余白、丸み、見出しの強弱で情報の段階を表す。評価額・数量・損益は桁をそろえ、金額に円記号と桁区切りを付ける。増益と配当金は「+」と緑、税額・損失は「−」と赤で示し、色に符号を添える。価格基準日・CSV 取込日はページ上部に明記する。表名・列名・金額・率・日付の書式は `docs/ui-design.md` と `frontend/src/ui/format.rs` の共通型に合わせた提案である。

## 利点とトレードオフ

最初に重要な数値をつかみ、必要な人だけ詳細を開けるため、読みやすさと一覧の見通しを保ちやすい。A より一画面に出る明細数は少なく、複数銘柄を一度に比較する作業は行の開閉を伴う。
