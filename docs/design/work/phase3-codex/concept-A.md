# コンセプト A：金融プロフェッショナル向けの高密度 UI

## 骨格

PC は細い左レールにアイコンとラベルを併記し、作業領域を広く確保する。資産管理は「一覧＋選択中の詳細」のマスター・ディテール構成。左の固定列テーブルで銘柄・口座・数量・評価額・損益を比較し、行を選ぶと右パネルに取得総額・基準価額・配当などを表示する。表の行高は28px、見出しは固定、数値列は右揃え・等幅数字・固定幅とする。

ホームは評価額などの集計帯を上段に置き、中段に配当推移と円グラフを配置。下段を評価損益上位と最近の配当入金に分け、一覧性を保ったまま複数ペインを同時に比較する。画面内の表示数を優先し、罫線と列の揃いで読み分ける。

スマホは左レールを上部の小さなページ見出しに置き換える。集計は2列の要約、資産は検索後に銘柄・評価額を1段目、口座・数量・損益を2段目に置いた高密度リストにする。横スクロールは設けず、資産管理では選択詳細を別画面で見る。取引明細は入金日・銘柄・税引後を主列にし、2段目にも税引前配当と税額を常時表示する。

## 視覚と言葉

濃紺の操作面、淡い作業面、細い罫線で業務用ワークスペースを表現する。評価額・数量・損益は桁をそろえ、金額に円記号と桁区切りを付ける。増益と配当金は「+」と緑、税額・損失は「−」と赤で示し、色に符号を添える。価格基準日・CSV 取込日はページ上部に明記する。表名・列名・金額・率・日付の書式は `docs/ui-design.md` と `frontend/src/ui/format.rs` の共通型に合わせた提案である。

## 利点とトレードオフ

一画面で比較できる数値と銘柄が多く、保有数が多いときの照合に向く。行高28pxと固定列幅は情報を詰められる一方、読み取り負荷が高くなる。スマホでは比較列を要約し、PC と同じ一覧幅を押し込まない。
