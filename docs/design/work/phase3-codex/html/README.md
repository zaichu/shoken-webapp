# コンセプト画面プレビュー

`index.html` をブラウザで開き、上部のリンクでコンセプト・画面・幅を選ぶ。実装・画像は架空データのみを使用。

- A: 金融プロフェッショナル向けの高密度UI
- C: 情報密度と視認性を両立したUI
- 画面: ホーム、資産管理(すべて)、取引明細(配当金)
- 幅: PC 1280×760、スマホ 390×844
- PNG は `../shots/` に各画面1枚ずつ保存。すべて150KB以下。

スクリーンショットは Playwright for Python で撮影し、全12枚を目視確認した。Figma MCP は Starter プランの呼び出し上限で編集できず、Section 9:8/9:10 は未作成。
