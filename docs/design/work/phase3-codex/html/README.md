# コンセプト画面プレビュー

`index.html` をブラウザで開き、画面上端の切替リンクから A/C、ホーム/資産管理/取引明細、PC/スマホを選ぶ。スマホ表示は幅390pxの枠内で iframe を使い、画面幅に応じたレイアウトを確認できる。A と C のホームにはライト/ダークの PC 表示もある。架空データを使用。

- A: 左の細い縦ナビ、密な一覧と詳細パネルのマスター・ディテール。資産表 PC 行高28px。
- C: 上ナビ、要点カードから展開式の詳細へ続く2段構成。資産表 PC 行高44px。
- 画面: ホーム、資産管理(すべて)、取引明細(配当金)
- PC: 1280×760、スマホ: 390×844
- `../shots/` に画面別 PNG とホーム PC のライト/ダークを保存。1枚150KB以下。

画面要素と共通書式は Phase 1 の画面調査、`docs/ui-design.md`、`frontend/src/ui/format.rs` に合わせた架空データの提案。プレビュー切替ナビは PC/スマホのどちらでも常時表示する。
