# 投資信託の基準価額の取得元(調査)

Issue #1429 段階1の調査結果。調査日時は 2026-10-20(JST、夕方〜夜)。実際にネットワークで確かめた事実だけを書く。

## 結論

- 取得元は **三菱UFJアセットマネジメントの「投信情報API」(公式・無料・登録不要・JSON)** を推奨する。調査した中で、自動取得を公式に想定している唯一の取得元
- 識別コードは **投資信託協会コード(8桁英数字)** を使う。ファンド名→協会コードは、資産運用業協会が公開する **NISA成長投資枠対象商品リスト(Excel)** で引ける(実在ファンド4件で確認)
- 三菱UFJアセット以外のファンド(ニッセイ・大和・SBI・野村・楽天投信など)は、規約上クリーンな無料取得元が見つからない。**対応できないファンドは CSV の値を使う**(国内株式で共有値が無いときと同じ扱い)
- Yahoo!ファイナンス・投信総合検索ライブラリーは技術的には取れるが、**双方とも自動取得を規約で明示禁止**しているため推奨しない

## 推奨: 三菱UFJアセットマネジメント 投信情報API

- 案内ページ: https://www.am.mufg.jp/tool/webapi/ (「投信情報APIでは簡単にお客さまのWEBサイトに三菱UFJアセットマネジメントのファンドの各種データを組み込むことができます」と公式が想定利用を明記)
- 利用規約: https://www.am.mufg.jp/tool/webapi/agreement.html
- 仕様書: https://www.am.mufg.jp/assets/pdf/tool/webapi/fund_api.pdf

### 実際に確かめた応答(2026-10-20 JST)

```
GET https://developer.am.mufg.jp/fund_information_latest/association_fund_cd/03311187
→ {"result":{"status":200,...},"datasets":[{
    "fund_cd":"253266","isin_cd":"JP90C000GKC6","association_fund_cd":"03311187",
    "base_date":"20261020","fund_name":"ｅＭＡＸＩＳ Ｓｌｉｍ 米国株式（Ｓ＆Ｐ５００）",
    "nav":44943,"cmp_prev_day":"369","percentage_change":"0.83",
    "netassets":13166462681047, ...}]}
```

- 基準価額 `nav`・前日比 `cmp_prev_day`(円)・`percentage_change`(%)・基準日 `base_date`・ISIN `isin_cd`・ファンド名が1リクエストで取れる
- 当日分の基準価額が当日夕方に反映される(10/20分を10/20夕方に取得。同日時点のYahoo!ファイナンスはまだ10/19分だったので、Yahooより速い)
- 基準日指定でも取れる:
  `GET https://developer.am.mufg.jp/fund_information_date/association_fund_cd/03311187/base_date/20261016` → nav 45,135・cmp_prev_day 206(10/16分。Yahooの時系列と一致を確認)
- 対象外の協会コード(ニッセイ `29313233`・大和 `04311181` を実測)は `{"result":{"status":404,...,"errors":{"error_list":[{"code":"E00026","message":"最新ファンド情報（指定ファンド）がありません。"}]}}` と判別可能な応答
- 協会コードのほか `fund_cd`(社内コード)でも指定可。eMAXIS Slim 全世界株式(オルカン、協会コード `0331418A`)も同じ形式で取得確認

### 規約上の扱い

「Web API利用規約」(2026-10-20 確認)より:

- §2 料金: 「当社は、本サービスをご利用いただくにあたり料金の徴収を行いません。」(無料)
- §4 禁止事項: 「本サービスにより取得した情報を不当に二次配布する行為」「本サービスの内容を不当に転載・複写・蓄積または転送する行為」等。いずれも「不当に」という限定付きで、**自動取得の禁止・アクセス頻度の制限にあたる条項は無い**
- §1: 「本サービスは、データの提供をお約束するものではありません。システム障害やその他の理由により、データの提供が遅延し、深夜・早朝になることや、データの提供を取りやめる場合もあります。」(ベストエフォート。失敗時は前回値・CSV値に戻す設計が前提)
- 用途は「WEBサイトへの組込」を公式が想定しており、APIとしてアクセスするのは想定内の使い方

### カバー範囲と限界

- 三菱UFJアセットマネジメントのファンドのみ(eMAXIS Slim シリーズ・eMAXIS・三菱UFJブランド等)。ユーザーが保有する有力候補(オルカン・S&P500・全米株式等のeMAXIS Slim系)はここでカバーできる
- ニッセイ・大和・SBI・野村・楽天投信等他社のファンドは対象外(404応答)。他社で同等の無料公開APIは、公式サイト・検索で調べた範囲では見つからなかった(同様の調査をした公開記事でも「国内で公式APIを公開しているのはここだけ」との観測)
- 全件一覧を返すエンドポイントは `/fund_list` `/fund_information_latest/all` 等を試した限り見つからず、1ファンド=1リクエスト(保有名柄程度なら問題ない)

## ファンド名→協会コードの対応

NISA成長投資枠の対象商品リスト(非上場投資信託)が使える。資産運用業協会が公開する公式データ:

- URL: https://www.imaj.or.jp/find/nisa_growth_productslist/xlsx-cms/unlisted_fund_for_investor.xlsx (案内ページ https://www.imaj.or.jp/find/nisa_growth_productslist/ からリンク。2026-10-20 時点の最終更新日表示は同日)
- 列に `投信協会ファンドコード`・`ファンド名称`・`運用会社名`・`設定日` 等がある(実ファイルで確認)
- sheet1 に約2,360行。以下の実在ファンドで「ファンド名→協会コード」の対応を実データで確認した:

| ファンド名(リスト表記) | 協会コード |
|---|---|
| ｅＭＡＸＩＳ　Ｓｌｉｍ　米国株式（Ｓ＆Ｐ５００） | 03311187 |
| ｅＭＡＸＩＳ　Ｓｌｉｍ　全世界株式（オール・カントリー） | 0331418A |
| ｉＦｒｅｅＮＥＸＴ　ＦＡＮＧ＋インデックス | 04311181 |
| ニッセイＮＡＳＤＡＱ１００インデックスファンド＜購入・換金手数料なし＞ | 29313233 |

- 名称は全角表記。セルのふりがなは `<rPh>` ルビ扱いなので値自体は正式名(全角)。証券会社CSVの表記(半角カナ・半角括弧・スペース揺れ・愛称の有無)とは正規化(全角統一・空白除去等)が必要になり得る
- カバー範囲は「NISA成長投資枠の対象商品」なので全投信ではない(対象外商品・設定直後・償還済み等は載らない)。引けないファンドは手動対応表かCSV値フォールバック
- 同様に金融庁の「つみたて投資枠対象商品リスト」も存在するが、成長投資枠リストのほうが対象が広い

## 他候補の詳細(規約の文面)

### 投信総合検索ライブラリー(資産運用業協会。旧投資信託協会) — 規約禁止

- https://toushin-lib.fwg.ne.jp/FdsWeb/FDST030000?isinCd=JP90C000GKC6 で eMAXIS Slim S&P500 の詳細を実測: 評価基準日 2026年10月19日・基準価額 44,574円・前日比 561円(1.24%)
- 公式の CSV ダウンロード機能あり: `…/FdsWeb/FDST030000/csv-file-download?isinCd=JP90C000GKC6&associFundCd=03311187` で設定来の日次基準価額CSV(Shift_JIS。列: 年月日・基準価額(円)・純資産総額(百万円)・分配金・決算期数)を実測取得、最終行 2026/10/19・44,574
- 詳細は ISIN キー。協会コードのみ(`associFundCd=03311187`)では詳細は空・CSVは `{"statusCode":null}` となる
- 「投信総合検索ライブラリーのご利用にあたってのご注意」の文面: **「○ 自動的な手段による情報の取得（Webスクレイピング、ロボットによるデータ収集、等）を禁止します。」** — 明示的な禁止のため採用不可(CSV手動DLは可、cronの自動取得は不可)
- 協会サイトポリシーにも「著作権法により、本協会に無断で転用、複製することはできません」とある

### Yahoo!ファイナンス(LINEヤフー) — 規約禁止

- `https://finance.yahoo.co.jp/quote/03311187` で eMAXIS Slim S&P500: 44,574円・前日比 -561(-1.24%)・10/19 と実測。`/history` で日次時系列(2026/10/19 44,574・前日差 -561 等)も確認。協会コードで直接指定できほぼ全ファンドをカバー
- LINEヤフー共通利用規約の文面(2026-10-20 確認):
  - §8.3 「お客様は、本コンテンツを、当社サービスが予定している利用態様を超えて利用（複製、送信、転載、改変を含みます。）をしてはなりません。」
  - §14 「当社サービス等の再利用の禁止」: 「お客様は、別途当社が定める場合を除き、当社サービスやそれらを構成するデータを、その提供目的を超えて利用することができません。」
  - §15(5) BOT・技術的手段による不正操作の禁止
- 公式ヘルプ記事「Yahoo!ファイナンス掲載情報の自動取得（スクレイピング）は禁止しています」(https://support.yahoo-net.jp/SccFinance/s/article/H000011276 )が存在し、機械的取得を明示禁止(ページはJS描画のため本文は未取得だが、規約条文だけでも禁止は明確)
- ファイナンス各ページのフッタにも「株式情報の転用、販売は固く禁じます。」の表示
- ※ 国内株式が使っている `query2.finance.yahoo.com`(米Yahoo社)とは別主体。日本の投信は Yahoo Japan 側のデータ。米Yahoo側のchart APIは本調査では429応答で可否未確認だが、Yahoo系の利用はいずれにせよ規約上禁止

### 日経(投信サーチ) — 規約上困難

- `https://www.nikkei.com/nkd/fund/?fcode=03311187` は協会コード指定で開けるが JS 必須で、スクレイピングは日経の利用規約上の制約あり。公開観測では価格反映も遅いとの報告

### 楽天証券・各証券会社 — 不可

- 楽天証券のファンド詳細ページは JS 必須・独自の内部IDで、公開ページの自動取得は証券会社の規約上認められていない

### 他の運用会社 — 自社分のみ・API 無し

- ニッセイAM(nam.co.jp)・大和AM(daiwa-am.co.jp)等は自社ファンドの基準価額ページ(例: `daiwa-am.co.jp/funds/detail/3346/detail_top.html` で iFreeNEXT FANG+ の基準価額・協会コード04311181を確認)があるが、無料の公開APIはなく、HTML取得はスクレイピング扱い

### J-Quants V2 — 投信データなし

- 公式のエンドポイント一覧(https://jpx-jquants.com/ja/spec/bulk-list/endpoints )は equities・indices・derivatives・markets・fins・calendar の21種で、**投資信託(非上場)のエンドポイントは無い**。APIキー利用の既存連携はあるが対象外

## 実装の見積もり(段階2以降の話)

1. テーブル: `security_prices` を投信でも使う場合は `security_code` に協会コードを入れる案、または投信専用の `fund_codes`(正規化ファンド名→協会コード)と `fund_prices` を分ける案。既存ビュー(`asset_balances_view`)が security_code 前提なら、投信の保有行に協会コードを持たせる形が自然。要DB設計
2. 名前の対応: 保有ファンド数は限られるため、(a) 手動対応表をDBに持つ、(b) NISA成長投資枠リストExcelを定期的に取り込み ファンド名(全角正規化)→協会コードで引く、(c) 引けないものは未対応としてCSV値を使う、の組合せ
3. 取得:cron を1日1〜2回(夕方以降。投信は1日1回しか値が決まらない)で、保有中かつ協会コード判明済みのファンドだけ `fund_information_latest` を叩く。応答の nav・cmp_prev_day・base_date を保存
4. フォールバック: 404/対象外/失敗時は CSV の値を使う(株の共有値なしと同じ扱い)。全件失敗は取得元変更を疑ってエラーログ(株と同じ思想)
5. 残件: 他社ファンドの対応は、公式APIの公開が出た時点で追加する前提。無理にスクレイピングしない

## やらなかったこと・注意

- 実装・コード変更は行っていない(調査のみ)
- ユーザーのCSV・保有データは使用していない。ファンド名は公開されている実在ファンドのみ使用
- MUFG API の同時接続・レート制限は未検証(保有ファンド数程度の日次アクセスなら問題ない想定)。仕様書PDFは文字コードの関係で内容を確認できておらず、エンドポイントは実測で確かめたもののみ記載
- NISA成長投資枠リストExcelの更新頻度・過去互換は未検証(実測した2026-10-20版で対応を確認したにとどまる)
